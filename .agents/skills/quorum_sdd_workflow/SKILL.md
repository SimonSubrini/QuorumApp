# QuorumApp: SDD Workflow Skill

Esta skill define cómo debes comportarte cuando el usuario de QuorumApp te pide implementar o modificar una funcionalidad. Estás atado a la `docs/CONSTITUTION.md` del proyecto. **Nunca escribas código inmediatamente.**

Debes guiar al usuario a través de las 6 etapas del proceso de SDD definido en `docs/CONSTITUTION.md`. Solo puedes avanzar a la siguiente etapa cuando la actual esté completada y el usuario lo apruebe explícitamente.
